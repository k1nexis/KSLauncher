# KS Launcher

Нативный лаунчер Minecraft на C# / WPF / .NET 8. Откройте `KSLauncher.sln` в Visual Studio 2022 или запустите:

```powershell
dotnet run --project .\KSLauncher.App\KSLauncher.App.csproj
```

## В приложении

- Полный список официальных Minecraft-релизов берётся из Mojang launcher manifest, поэтому версии не зашиты в XAML. Snapshots и старые preview-версии можно показать отдельным переключателем.
- Независимые игровые каталоги для версии и загрузчика; установка и запуск Vanilla, Fabric, Quilt, Forge и NeoForge через CmlLib.
- Встроенный менеджер Modrinth: поиск модов, модпаков, ресурспаков и шейдеров, фильтры по Minecraft/loader, загрузка прямо в каталог выбранного инстанса. Для модов скачиваются обязательные зависимости, проверяется SHA-512, имя файла очищается от traversal, размер ограничен 512 MiB.
- Microsoft OAuth для Minecraft Java; офлайн-профили; отдельный вход KS System к своему API.
- Локальная настройка фона изображением или MP4, сохранённая в настройках пользователя. Видео без звука и повторяется; поддерживаемые кодеки зависят от Windows.
- Темная WPF-тема; контролы, ползунок и прокрутка оформлены в палитре лаунчера.
- Настройка heap с предупреждением. JVM видит доступные логические потоки автоматически; G1GC включён, String Deduplication — переключаемая опция.

Профили игры и файлы: `%AppData%\KSLauncher\instances\<версия>-<loader>`. Настройки интерфейса: `%AppData%\KSLauncher\launcher-settings.json`.

## KS System / Cloudflare

Каталог `cloudflare/` содержит страницу Pages для регистрации/входа и ссылки скачивания, API Worker, миграции D1, хранение косметики в одном R2 bucket и portable build в отдельном release bucket. Worker не раздаёт Minecraft-лицензии, а аккаунт KS System не является игровым аккаунтом. Для публикации сайта и файла см. [cloudflare/README.md](C:\Users\k1nexis\OneDrive\Документы\ChatGPT\KSLauncher\cloudflare\README.md). Настройки Worker и ID базы нужно заполнить перед deploy; portable EXE релиз нужно вручную загрузить в R2.

## Важные ограничения

- CurseForge API не подключён; менеджер использует Modrinth API.
- Для модов профиль загрузчика должен совпадать с версией/loader выбранными на главной. Некоторые проекты могут зависеть от закрытых или явно несовместимых файлов и не установятся.
- Для модпаков `.mrpack` файл скачивается в папку профиля; импорт манифеста/overrides как готового инстанса ещё не реализован.
- Ely.by OAuth и интеграция с игровыми сессиями пока не подключены.
- Автоматическая генерация мира не форсируется по всем ядрам. Для предгенерации чанков нужен мод вроде Chunky и управляемая задача в мире.
- Фон MP4 выбирается локально; поддержка воспроизведения зависит от кодеков Windows. Вход KS System не требуется для локального оформления.

Сборка portable single-file для Cloudflare R2 описана в `cloudflare/README.md`. Не публикуйте `TOKEN_SECRET`, Microsoft секреты или пользовательские токены в репозитории.
